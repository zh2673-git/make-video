# make-video 职能分工总论

> 依据：01-项目方案.md | 本篇是**角色视角的总宪章**：部门制、职责矩阵、
> 工件交接制度、反模式库组织、人机协作触点。
> 各部门（角色）的施工规格在 03-09；公共法律在 10；公共注册库在 11。

## 一、为什么是部门制

1. **做视频的本质是像拍电影那样思考**——电影工业用百年时间沉淀了"谁对什么负责"
   的分解，这是最可靠的视频生产方法论。
2. **角色 = 专业容器**：职责 + 理论锚点 + 转译规则 + 工件 + 校验器 + 模板 + 反例
   + 标杆。打磨 = 按容器逐项过检。
3. **翻译损耗是最大事故源**（电影前置制作方法论的第一危险；LLM 流水线里每次
   模型调用都是一次翻译）——用**工件化交接**显式管理（ADR-9）。

### 工件契约三律

1. **每工件必过 schema**（zod）后才算交付；
2. **每工件必可人工编辑**（落 IR 或源码，非黑盒中间态）；
3. **每工件必进确认或报告**（A3/A4 进确认表；A8/A10/A12 进报告与日志）。

## 五、重角色交付前检查单

| 角色 | 交付前必过 |
|---|---|
| 编剧 | 每段有功能标注；beats 关键节点全覆盖；字数在档位区间；钩子在前两段；无信息倾倒三段连 |
| 导演 | 每镜风格/素材决策有理由；对位模式三选一已填；导演批注已生成并进确认表 |
| 分镜师 | 段数=镜数；一镜一单元；景别序列合规；同场景轴线一致 |
| 表演 | 主体有动机声明；重音帧有姿态设计；长镜有 idle 微动；停止有缓出 |
| 剪辑师 | 剪切点全部落在候选集；密度曲线符合档位；呼吸镜间隔达标；重音三联动 |

## 七、人机协作触点地图（混合工作流的界面）

| 触点 | 工件 | 人的动作 | 系统响应 |
|---|---|---|---|
| 立项 | A1 | 给主题/素材/约束 | init + doctor |
| 创意判断 | A3/A4 | 改批注/改决策表 | 只重生受影响镜头 |
| 逐镜微调 | A5 | 改某镜 kind/素材/景别 | `retry --shot sXX` |

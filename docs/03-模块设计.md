# MakeVideo 模块设计（接口契约 + 执行流）

## 接口契约总表

### 1. 分镜 DSL v2（core/schema.py — Scene 契约）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | str | ✅ | 分镜号（如 01、09b），用于音频/分段缓存命名 |
| type | enum | ✅ | title/bullets/flow/**stat**/table/panorama/ending/quote/compare/timeline/chart/code/image |
| title | str | ✅ | 分镜标题（title/ending 为大标题） |
| narration | str | ✅ | 旁白（TTS 输入，空则断言失败） |
| subtitle | [str] | — | title/ending 副标题行 |
| bullets | [str] | — | bullets=要点；flow=步骤；compare=左右条目；timeline=节点；code=行 |
| header/rows | [[str]] | — | table/panorama/chart 表头与数据行 |
| highlight | str | — | table 行高亮关键词 |
| cellColors | map | — | 语义色映射（业务色由数据携带，主题提供缺省） |
| leftTitle/rightTitle | str | — | compare 左右栏题 |
| icons | [str] | — | bullets/stat 条目图标名（v0.0.4，按序对应，缺项回退序号；engine 内嵌 feather 风格 SVG） |
| stats | [[str]] | — | stat 版式数据行：[值, 标签, 图标?]（值中数字部分自动计数滚动） |
| quote | str | — | quote 正文金句 |
| attribution | str | — | quote 出处 |
| lang | str | — | code 语言（决定高亮色系，仅配色不词法分析） |
| image | str | — | image 分镜文件名（相对工程 public/） |
| imageNote | str | — | image 注解 |
| note | str | — | 页脚注 |
| captions/frames/audio/audioSec | — | 运行时生成 | 不入 DSL，由管线计算 |

### 2. 讲稿格式（human 接口）

```markdown
<!-- meta: voice=zh-CN-YunjianNeural rate=+0% unit=示例单位 author=主讲人 -->

## SCENE 01|title|示例：从讲稿到成片
subtitle: 讲稿驱动的微视频生成工具
=== narration
大家好……

## SCENE 02|bullets|工具解决什么问题
- 要点一
=== narration
……
```

**规则**：`## SCENE id|type|title` 开块；`=== narration` 分隔画面区与旁白区；画面区支持 subtitle:/行、`- ` 条目、`|` 表格、highlight:/note:/quote:/attribution:/lang:/image:/imageNote:/leftTitle:/rightTitle:/icons: 指令。仅用基础六型的早期格式讲稿零改动兼容。

### 3. 工程配置（projects/{name}/project.json）

| 字段 | 说明 |
|---|---|
| name | 成片名（默认目录名） |
| script | 讲稿路径（默认 讲稿.md） |
| theme | 主题名（对应 themes/{theme}/theme.json） |
| meta | voice/rate/unit/author/compliance/footer（覆盖讲稿内嵌 meta） |
| output | 成片相对路径（默认 out/{name}.mp4） |

### 4. 主题契约 theme.json（六段式）

| 段 | 内容 | 消费者 |
|---|---|---|
| palette | primary/primaryDark/primaryLight/accent/accentSoft/surface/surfaceCard/surfaceAlt/ink/inkMuted/onPrimary | 全组件 |
| semantic | success/info/warning/highlightRow（业务缺省色） | TableScene/CompareScene |
| typography | body/mono 字体栈 + display/title/header/h1/h2/bodySize/caption/micro 字号阶 | 全组件 |
| motion | entranceSpring{damping,stiffness}/stagger/tableRowDelay/fadeFrames | 动效 |
| layout | safeMargin/headerHeight/footerHeight/subtitleBottom/radius | Shell/SubtitleBar |
| brand | coverBg/headerBg/footerBg（完整 CSS 渐变串）/serialLabel | 封面/页眉页脚 |
| variants（可选） | {bullets/flow/stat/table/quote/compare/timeline: [变体名,…]}，v0.0.2（stat v0.0.4） | 动效轮换（pickVariant） |

**注入方式**：渲染前 Python 将选定主题复制为 `engine/src/theme.gen.json`（与 scenes.gen.json 同模式），Root.tsx import——零新依赖，产物可追溯。

### 5. CLI（runtime/cli.py 对外接口）

```
python -m makevideo build  <projectDir> [--only id,id] [--no-tts] [--no-render] [--theme X]
python -m makevideo compose <textFile> [-o out.md] [--dry-run] [--ai] [--prompt-out 路径]
      # 纯文本 → 分镜草稿：缺省规则链（v0.0.2，离线兜底）；--ai 走 LLM 排版决策（v0.0.5，OpenAI 兼容协议）
      # --prompt-out 不发请求：落盘「SKILL.md 规范+原文」任务包，交给任意 LLM 环境回填后 build
python -m makevideo import-themes <designMdDir> [--only 名,名] [--force]   # awesome-design-md 批量移植（v0.0.3）
python -m makevideo preview <themeName> [--out dir]      # 主题6宫格试帧（跳过TTS，定长帧）
python -m makevideo validate <projectDir>                # DSL+theme+工程配置校验，不出片
python -m makevideo list-themes                          # 列出主题库
```

## 执行流模式（顺序管道 + 生命周期钩子）

| 钩子 | build 全量 | build 增量 | preview |
|---|---|---|---|
| init | 读工程配置→解析讲稿→DSL 校验→载入主题→校验 | 同左 | 载入主题→构造固定样例分镜 |
| start | 逐分镜 TTS→帧数对齐→字幕帧窗→写 scenes.gen.json + theme.gen.json | 复用/重渲分段判断 | 写 gen.json→渲染样例帧区间 |
| stop | 音频数=分镜数断言 | 缺失段自动补渲 | 退出码断言 |
| destroy | Remotion 渲染（整片或分段+拼接）→成片落盘 | 同左 | 试帧 PNG 落盘 |

失败即停：任何断言失败/子进程非零退出 → sys.exit 带错误码，不产生半成品成片（分段模式下旧成片保留）。

## 模块依赖方向（防越界铁律）

```
runtime/cli ──→ application/pipeline ──→ domain/{parser,composer,captions,timeline,designmd}
       │                    │                     ↑ 纯函数，不依赖 infrastructure
       │                    └──→ infrastructure/{tts,renderer,themeio}
       └──────────────────────────→ core/schema（全员只依赖 core）
engine/（TS 侧）只消费 gen.json 产物，与 Python 层零运行时耦合
```

禁止：domain import infrastructure；themes 反向被 styles 依赖；engine 读业务 CSV。

### 6. 自动分镜（domain/composer.py，v0.0.2）

- `compose_script(text) -> scenes`：纯文本 → 分镜草稿（含 `_why` 决策依据）。规则链首中即停：code → table/panorama → chart → timeline → compare → flow → quote → bullets（兜底）；首段→title、收束语段→ending；条目超限自动分块（bullets 6 / flow 4 / chart 6）。
- `render_markdown(scenes) -> str`：草稿 → 讲稿.md（与 parser 语法对偶）；pipeline.compose_script 落盘后回读复验（DSL round-trip）。

### 7. 主题批量移植（domain/designmd.py，v0.0.3）

- 一级解析 `parse_frontmatter`：YAML frontmatter 子集（缩进嵌套、引号内取值容忍行内注释），64/74 份上游文档覆盖 colors/typography/rounded。
- 二级解析 `parse_prose_colors`：散文角色标注行（`**名称** (`#hex`)：角色`）按"章节+标签+说明"分类，覆盖 10/74 份。
- `extract_font_stacks`：Font Family 章节 fallback 反引号串 → 正文字体栈（过滤文字变体切割、补 CJK 安全栈）；mono 恒用默认栈。
- `build_theme`：候选链首中即停 + 色彩数学兜底（mix/darken/lighten/hue_rotate、RGB 距离去重校验、WCAG 亮度定深浅与 onPrimary）；字号阶为画布常量；brand 渐变按 surface 亮度分深浅模板。返回 (theme, 兜底备注)。
- `pipeline.import_themes`：遍历 design-md/<folder>/DESIGN.md → 转换即校验（save_theme 先 E3 后落盘 + 回读复验）→ themes/<slug>/theme.json + styles/<slug>/DESIGN.md（溯源头 + 推导备注 + 第 10 节默认档）。同名主题跳过（--force 覆盖）。

### 8. LLM 排版决策后端（SKILL.md + infrastructure/llm.py + pipeline，v0.0.5）

compose 的三种模式（同一输入，三种作者权分工）：

| 模式 | 触发 | 决策者 | 内容边界 |
|---|---|---|---|
| 规则链（缺省） | `compose 文本` | composer 启发式规则 | 条目逐字取原文，版式由文本形态判定（离线兜底，防幻觉） |
| LLM 写讲稿 | LLM 读 SKILL.md 后直接产出讲稿 | LLM（作者模式） | 内容+版式+图标+主题建议全由 LLM 创作 |
| compose --ai | `compose 文本 --ai` | LLM（排版模式） | 版式/图标/分镜切分由 LLM 决策，条目与 narration **逐字取原文** |

关键部件：
- **SKILL.md（仓库根，单一源头）**：LLM 创作引导规范（13 版式选型决策表 / 图标名清单 / 语速与时长纪律 / 自检清单）。作者模式直接读；`--ai` 模式作为 system prompt 注入（`_AI_ROLE` 追加排版模式铁律）。
- **infrastructure/llm.py**：OpenAI 兼容 `/chat/completions` 客户端，纯 stdlib（urllib，零第三方依赖）。环境变量 `MAKEVIDEO_LLM_BASE_URL`（缺省 openai）/ `MAKEVIDEO_LLM_API_KEY` / `MAKEVIDEO_LLM_MODEL`；配置缺失或调用失败一律 E7。
- **pipeline 护栏**：LLM 草稿过真实 `parse_script + validate_scenes`（E2），失败将错误回喂重试 1 次，两次仍失败抛 E2 拦截；落盘后 round-trip 复验。`--prompt-out` 离线任务包（HTML 注释包裹 system/user）供任意 LLM 环境回填——无 API key 时的等价通道。

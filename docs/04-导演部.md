# 导演部（M3 storyboard：导演 + 分镜师）

> 角色：导演（决策）+ 分镜师（镜头化）| 上游：编剧部（A2）| 下游：采购部/美术摄影部/
> 剪辑部（A5）、用户（A4 确认门）| 模块：M3 | 校验域：V-COMP-007/008、V-RHY-001/002/007、
> V-CP-001/002、V-STYLE-001 | 反例卷：导演卷/分镜卷

## 部门职责

导演部是全片的**创意决策中枢**，干三件事：

1. **意图显式化**（导演）：把讲稿转成导演批注（A3）——每段的视觉意图、情绪目标、
   参考气质、对位模式。这是 ADR-9 的核心工件：没有它，分镜就是“翻译损耗”的开始；
2. **镜头化**（分镜师）：把讲稿切成语义单元镜头（A5 shot list），每镜带景别、
   相机运动及动机、对位模式；
3. **两大决策**：每镜的**素材决策**（画/用我的/导入/云生成）与全片**风格决策**
   （带 source + rationale，无默认风格）。
4. **风格沉淀**（本部新增职责）：用户给参考素材或说"想要 XX 的感觉"时，三态决策——
   选用既有包 / 覆写（base+override）/ 新建（`absorbStyle`），产出解剖卡与沉淀档案。

## 理论锚点

| 理论 | 转译 |
|---|---|
| 场面调度（mise-en-scène） | 构图/空间/光线/运动统一调度——导演批注的四要素模板 |
| Director's notes 方法论 | 剧本→分镜之间的意图显式化（AI 导演工作流的第一产物，业界已验证）→ A3 |
| Pre-visualization | 先视觉化后执行 → 确认表（A4）先于一切采购 |
| 景别七级系统 | A5 shot.zoom ∈ {ELS,LS,MLS,MS,MCU,CU,ECU} → 主体占比 token |
| 180°轴线 / 30°规则 | V-COMP-007（同场景方位一致）/ V-COMP-008（连续景别差≥2 级） |
| 库里肖夫效应 | 镜头并置生第三意义 → V-RHY-007 镜头粒度=语义单元 |
| 声画对位（爱森斯坦 1928） | V-CP-001/002：画面禁复述旁白，对位三选一必填 |

## 输入输出工件

- **输入**：A2 讲稿 + recipe（beats + directorialNotes 模板 + style 推荐）+
  materials 库存索引（采购部 A11 的雏形）+ 分类轴结论。
- **输出工件**：
  - **A3 导演批注** `DirectorNotes[{segmentId, visualIntent, emotionGoal, referenceMood, counterpoint}]`
  - **A4 确认表** `ConfirmTable[{shotId, materialDecision, styleDecision, rationale}]`（含批注摘要）
  - **A5 shot list** = IR `shots[]`（旁白/VisualSpec/景别/相机+动机/对位/transition）
- **输出工件（风格侧）**：
  - **A13 风格解剖卡** `StyleAnatomy`：按部门键的指令集（script/directing/art/camera/
    performance/sourcing/sound/editing），用户可读、agent 可执行；
  - **A14 风格沉淀档案** `StyleProvenance { source, from, version, grade, review }`。

## 两大决策规则

### 素材决策（每镜）

| 稿子内容 | 库存状态 | 决策 |
|---|---|---|
| 抽象概念/数据/流程/情绪空镜 | 任意 | `code-scene` |
| 具体指称物（产品/真人/地点/品牌） | 库存有匹配 | `user-material` |
| 具体指称物 | 库存无匹配 | 按 policy：ask→A4 询问 / code-first→code-scene / real-first→cloud 或 imported |

### 风格决策（全片）

- 来源三选一：`recipe-recommended`（L1 预绑）/ `agent-chosen`（须过一致性校验器）/
  `user-specified`；**必须带 rationale**（V-STYLE-001）；agent 无法论证 → 进 A4 询问。
- 组合三级纪律见 11；谱系记 IR。

## 模块四层设计（M3）

- **数据规范**：`Shot`/`VisualSpec`/`DirectorNotes`/`ConfirmTable`/`StyleDecision`
  zod schema；`VisualSpec.kind ∈ code-scene|user-material|imported|cloud`；
  `shot.counterpoint ∈ metaphor|evidence|emotion` 必填（V-CP-002）；
  `shot.zoom`/`camera`/`motivation` 必填（V-CAM-002）。
- **数据存储**：shots[]/批注/决策落 `project.json`；LLM 原始响应落 `cache/storyboard*.json`；
  每镜 `scenes/Scene_s<NN>.html` 占位（由美术摄影部填充）。
- **数据流转**：
  ```
  A2 → writeDirectorNotes（LLM，模板来自 recipe.directorialNotes）→ zod 校验 → A3
     → storyboard（以 A3 为约束：recipe 实例化 → LLM 分镜 → 素材决策（规则表）→
        风格决策 → 规则校验：段数=镜数/一镜一单元/景别序列/轴线/对位必填）
     → 写 IR → buildConfirmation → A4 → （阶段门：用户确认事件才进 sourcing）
  ```
- **数据接口**：`writeDirectorNotes(p, script): DirectorNotes`；
  `storyboard(p, script): Shot[]`；`buildConfirmation(p): ConfirmTable`；
  `classify(request): GenreMatch[]`（六轴分类，委托 M10）；
  `absorbStyle(p, source): StyleDraft`（风格沉淀，见下）。
- **生命周期钩子**：`init(ctx)` 注入 llm-client、style-registry、material-indexer；
  `start/stop` 无长驻资源；`destroy` 显式声明无操作。

## 风格沉淀用例（absorbStyle）

**三层沉淀模型**（风格知识不每次重推）：

| 层 | 沉淀什么 | LLM 何时介入 |
|---|---|---|
| T1 制度 | 吸收的方法：部门制/工件链/校验器/对拍门禁/匹配优先（风格无关） | 从不 |
| T2 内容 | 每个注册风格的部门指令集（参数+anatomy+反例） | 从不——生成期读登记指令 |
| T3 感知 | 新风格吸收时的理解 | **仅一次**：按 anatomy 部门键表格填空，可审可改 |

```
absorbStyle(p, source):
  ① 输入解析：参考视频（ffmpeg 抽帧）/图片/文字描述；
     agent 多模态分析（本会话 vision 模型；不可用则用户口述补齐）
  ② 匹配优先：与既有风格包按特征比对
     → 高度相似 → 建议 base+override（防风格库爆炸）
     → 差异显著 → 按 anatomy 部门键 schema 生成草稿包（M10 三态：draft）
  ③ 解剖填空与确认：展示 A13 解剖卡给用户确认/修正
  ④ 小样对拍：草稿包渲染测试片 vs 参考帧并排 review（状态 → candidate）
  ⑤ 上架：达标 → status=registered（评 grade，初评多 B）→ A14 归档；
     不达标 → 迭代参数或淘汰（记反模式）
```

**执行纪律（V-STYLE-007）**：registered 风格的生成 = 读登记指令 + 受限细化；
**禁止逐镜重新解释风格**（防风格漂移 + 降成本 + 保可解释）；要偏离登记指令，
必须走 override/absorb 显式流程。

**版权纪律**：沉淀提取的是**语法**（构图关系/色彩关系/节奏结构），不是素材；
参考帧只进本地对拍目录，**禁止任何参考帧进入成片**；references 只存解剖描述 +
用户自有参考缩略图。

## 反例（导演卷/分镜卷种子）

| 反模式 | 部门 | 现象 | 根因 | 对策 |
|---|---|---|---|---|
| 看图说话 | 导演 | 画面复述旁白字面 | 把对位当解释 | V-CP-001 |
| 无依据风格 | 导演 | "因为默认选了它" | 偷懒 | V-STYLE-001 |
| 无批注直分镜 | 导演 | 翻译损耗失控 | 跳过 A3 | 流程门（ADR-9） |
| 一镜多义 | 分镜 | 一个镜头塞两个观点 | 忽视库里肖夫单元 | V-RHY-007 |
| 句中切镜 | 分镜 | 剪切点落在句中 | 按字数均分切镜 | V-RHY-002 |
| 同景跳轴 | 分镜 | 主体左右横跳 | 无轴线意识 | V-COMP-007 |

# 05-主题系统-四层设计（styles/ + themes/ + infrastructure/themeio）

- **本质**：在"成片运行时"的时空约束下，本模块是把设计哲学（人读）翻译为渲染 token（机读）的**风格翻译器**——风格空间与内容空间解耦的关键层。
- **数据规范**：theme.json 六段契约（docs/03 §4）；字段缺失→ThemeError 列出缺失键；未知键→告警忽略（向前兼容）；颜色一律 `#RRGGBB`/`rgba()`；渐变为完整 CSS 串（转换规则已把 DESIGN.md 语义具体化，组件零拼接）。
- **数据存储**：
  - `styles/{name}/DESIGN.md`：设计系统文档（人审源头，双源头：awesome-design-md 移植 / canvas-design 原创），含第 10 节 Motion & Video Rules。
  - `themes/{name}/theme.json`：token 唯一契约面；全局共享只读，工程不修改主题。
  - `engine/src/theme.gen.json`：渲染前由 Python 从选定主题复制（生成物，可追溯）。
- **数据流转**：DESIGN.md →（skill 流程：AI 读文档生成 token 草案 → 6 宫格试帧人审 → 定稿）→ theme.json。转换规则（编译期固定）：色板/字体层级/布局原则直接映射；hover/active/disabled 交互态与响应式断点**过滤**（固定 1920×1080 画布）；阴影层级→卡片层次参数；第 10 节动效→motion 段。
- **数据接口**：`load_theme(name) → dict`（themeio）；`validate_theme(dict)`（core/schema）；`list_themes() → [name]`。
- **动效变体池（v0.0.2）**：theme.json 可选段 `variants`——`{bullets/flow/table/quote/compare/timeline: [变体名,…]}`，1~4 个变体名；组件按**同版式出现序号**轮换（相邻分镜不重复），第 1 变体为默认动效（与缺省行为一致）。缺省该段即纯默认动效，旧主题零改动兼容；结构错误（未知版式名/空池）→ ThemeError 拦截。变体仅动效维度（位移方向/时序），布局与色彩 token 不变；各主题第 10.1 节记录取值。
- **生命周期钩子**：init=载入+校验（token 空间开辟）；start/stop 无（静态数据）；destroy=无（只读共享空间，不回收）。
- **首发主题**：govgold 政务红金（原创）、chalkboard 黑板手写（原创）、magazine 极简杂志（移植）、techdark 科技暗色（移植）、warmedu 暖色教育（原创）。

# 美术摄影部（M4 scene-forge：美术指导 + 摄影指导 + 表演）

> 角色：美术指导（画什么）/ 摄影指导（怎么拍）/ 表演（怎么演）| 上游：导演部（A5）|
> 下游：剪辑部（场景文件）| 模块：M4 | 校验域：V-SCENE-*、V-COMP-*、V-MOT-*、
> V-CAM-*、V-ACT-*、V-COL-* | 反例卷：美术卷/摄影卷/表演卷

## 部门职责

把 A5 的 `visualSpec` 编译为**可渲染的动效场景代码**（HTML/CSS/GSAP + 内联 SVG）。
三个角色一张图：

- **美术**：分层构图 + 设计 token（色彩脚本落地）——画面的秩序与一致性；
- **摄影**：景别实现 + 相机运动 + 光影质感层——画面的镜头感与电影感；
- **表演**：主体的“演技”——anticipation/姿态/重量感/idle 微动——画面的生命感。

这不是“AI 随便画图”，而是**模板选择 + 数据注入 + 受限代码生成 + 校验**的确定性
流程，LLM 只在“个性化”环节介入且输出必须过校验。

## 理论锚点

| 理论 | 转译 |
|---|---|
| 色彩脚本（皮克斯传统） | 风格包 `colorArc` 按叙事弧规划每镜色温 → V-COL-002/003/004 |
| Design token | 跨镜一致性的规则载体；换肤只换 token → V-COMP-006 |
| 三点布光/景深/明暗对比 | 光影质感层：径向渐变主/补/轮廓光、分层景深、暗角、颗粒 → 风格包 effects |
| 相机六式（推拉摇移跟随急推） | V-CAM-001~006：动机/安全区/分层/次数纪律 |
| 动画十二原则 | V-MOT-001~008：anticipation/staging/arcs/timing/follow-through/exaggeration |
| 格式塔共同命运 | V-MOT-010~012：同屏运动 ≤3、方向 ≤2、同组共用缓动阶梯 |
| Ed Hooks 动画表演 | V-ACT-001~006：动机/姿态/预备/重量感/idle/视线 |
| GSAP 现成配方 | stagger、逐字打字、SVG 描线、motionPath、matched-motion 转场 |

## 输入输出工件

- **输入**：A5 shot（visualSpec + tokens + motion profile）+ 风格包参数（M10 解析）+
  模板库索引。
- **输出工件**：
  - **A6 token set + 摄影计划**：色板/字号阶/每镜景别实现与相机参数；
  - **A7 表演设计**：主体动作曲线/情绪姿态关键帧/重音帧姿态；
  - 场景源码 `scenes/Scene_s<NN>.html`（LLM 生成、人可精修；不含时间轴属性）。

## 模块四层设计（M4）

- **数据规范**：
  - `SceneProps { shot, tokens, motion, frame }`（zod，core）——场景数据契约；
  - `SceneTemplate { id, kind, slots[], paramsSchema, refs }`，kind ∈
    chart/flow/atmosphere/typography/comparison；
  - `DesignTokens`/`MotionProfile`（由风格包注入，场景只读）；
  - **场景文件结构约定**：根元素 `data-scene-id`；槽位 `data-slot`；
    **禁止** `data-start/data-duration/data-track-index`（时序只许剪辑部机器生成，
    V-SCENE-002 ↔ V-CMP-002）。
- **数据存储**：场景源码落 `projects/<id>/scenes/`（项目独占，可精修）；
  模板库/动效库/token 库在 skill 侧 `templates/`（**只读共享**）；
  LLM 原始响应落 `cache/scene_s<NN>.json`。
- **数据流转**：
  ```
  visualSpec → ①模板选择（能套不自由生成，V-SCENE-001）
    → ②参数装配（tokens + motion + shot 数据 → SceneProps，zod）
    → ③LLM 个性化（模板骨架 + props + prompt；系统约束：只许调原语/只许填槽位/禁时序）
    → ④校验关卡（schema/结构/引用/主语唯一/对位关键词扫描；不过 → 带错重试 ≤3 → failed）
    → ⑤写 scenes/ + 缓存 → 镜头 sourcing(code 路径) 完成
  ```
- **数据接口**：`drawScene(p, shotId): void`（幂等：产物存在且校验过则跳过）；
  `listTemplates(): SceneTemplate[]`；`validateSceneFile(path): Issue[]`。
- **生命周期钩子**：`init(ctx)` 加载模板索引、校验动效/token 库版本兼容（不兼容
  fail-fast）；`start()` 准备校验器实例（无长驻进程）；`stop()` 停止接新请求、
  等在途 LLM 调用落盘；`destroy()` 显式声明无进程需释放。

## 第2层子模块

### motion-lib 动效库（含 performance 原语组）

- 本质：把 10 的动效/表演不变量固化为**可复用原语**——动效不重写，只调原语。
- 规范：六类原语 `enter/exit/emphasis/transition/camera/subtitle` +
  **performance 组**（anticipation/pose-change/weight-settle/idle-breath/eye-line）；
  参数化（duration/ease/delay/stagger/intensity 受 MotionProfile 约束）。
- 存储：`templates/motion/*.js`（GSAP 封装），版本 + 兼容矩阵。
- 流转：场景 import 原语 → 剪辑部注入 MotionProfile 覆盖默认参数。
- 接口：`listPrimitives()`；白名单供 V-SCENE-003 校验。

### design-tokens 设计令牌

- 本质：跨镜/跨项目一致性的规则载体——“换肤只换 token”。
- 规范：色板（主1/强调1/中性5）、字体族 ≤2、字号阶（相对屏高）、圆角/阴影/密度。
- 存储：`templates/tokens/base.json`；风格包 palette/type/layout 组覆盖。
- 流转：风格包 → 剪辑部注入 → 场景根 CSS 变量。
- 接口：`resolveTokens(stylePack): TokenSet`。

### template-gallery 模板库

- 本质：常见镜头范式的沉淀——“惊艳”的复用单元，标杆对拍的落点。
- 规范：`SceneTemplate`；每模板带 references（标杆实例）+ antiPatterns。
- 存储：`templates/scenes/<kind>/*.html`。
- 流转：导演部分镜时 visualSpec.kind 与模板 kind 对齐；本部 ①步选择；
  recipe 声明各类型偏好模板集。
- 接口：`listTemplates()/getTemplate(id)`。

# 06-渲染引擎-四层设计（engine/ Remotion 工程）

- **本质**：在"成片运行时"的时空约束下，本模块是消费分镜 JSON 与主题 token、把每帧时间点物化为画面的**逐帧画面工厂**。
- **数据规范**：
  - `SceneTypes.ts`：Scene 类型（与 Python core/schema.py 对偶，编译期守门）。
  - `theme.ts`：Theme 类型 + `cssVars(theme)` 注入 CSS 变量 + `useTheme()` Hook。
  - 组件映射表：12 型 → 组件一一对应（`MicroCourse.tsx` exhaustive switch，漏型编译报错）。
- **数据存储**：`src/scenes.gen.json` + `src/theme.gen.json`（Python 生成物）；`public/audio/scene-*.mp3`；`public/media/`（image 分镜素材）；`out/`（成片+分段缓存）。
- **数据流转**：Root（Composition 1920×1080@30fps，总帧=Σframes）→ MicroCourse（Sequence 编排，帧偏移累加）→ SceneView（fade 入场 + Audio 内嵌 + SubtitleBar）→ 具体分镜组件。表格逐行 interpolate 延迟入场；bullets/flow 逐项 spring stagger。
- **数据接口**：Composition id=`microcourse`；渲染入口 `npx remotion render src/index.ts microcourse <out> [--frames a-b]`。
- **生命周期钩子**：init=import gen.json（结构不符即编译/加载失败）；start=逐帧渲染；stop=子进程退出码断言（Python 侧）；destroy=产物落盘（分段缓存复用策略见 07）。
- **主题消费纪律**：组件内**禁止**出现十六进制色值/字体族字面量（除继承 token 的 alpha 变体）；业务语义色（如交叉类型色）由 scene.cellColors 数据携带，主题 semantic 段仅作缺省。
- **组件清单**：Shell（页眉页脚版式）/ SubtitleBar / TitleScene / EndingScene / BulletsScene / FlowScene / TableScene（table+panorama 双密度）/ QuoteScene / CompareScene / TimelineScene / ChartScene（柱状，纯 div）/ CodeScene / ImageScene。

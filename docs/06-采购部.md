# 采购部（M5 asset-sourcing）

> 角色：素材采购（制片执行面）| 上游：导演部（A5 决策记录）| 下游：剪辑部（就绪资产）|
> 模块：M5 | 校验域：V-AST-* | 反例卷：采购卷

## 部门职责

按 A5 的决策把每镜的视觉资产落到项目空间，管四件事：**四级来源分派**
（代码绘制/用户素材/导入复用/云端生成）、**归一化**（分辨率/帧率/时长统一）、
**同权标记**（所有来源资产统一过相机层+调色层+动效层）、**有界轮询**
（吸收云端不确定性）。采购部是“最节省”主线的执行者：代码绘制默认、云端兜底。

## 理论锚点

| 理论/实践 | 转译 |
|---|---|
| 素材资产管理（制片工业） | 每镜资产独立登记（AssetRef），按镜隔离目录，可追溯 |
| 版权实践 | 只处理用户自有/用户指定文件；网络 URL 导入需用户确认来源；云生成产物标注 provider/model 并在交付时附版权归属 |
| 隔离原则（工程铁律） | 素材按项目目录隔离，禁写共享目录——从结构上排除跨项目串音/覆盖 |

## 输入输出工件

- **输入**：A5 shot.visual（kind + 素材指向）+ `materials/` 用户素材 +
  policy（auto/ask/code-first/real-first）。
- **输出工件 A11 资产清单**：`materials/index.json`（用户素材元数据+标签）+
  各镜 `AssetRef { kind, path, durationMs?, width?, height?, meta }`（登记入 IR）。
- **同权标记**：AssetRef.meta 必须完整（静图标记 kenBurns=true 等），
  供剪辑部统一处理（V-AST-004）。

## 决策规则（分镜期已定，本部执行）

| 稿子内容 | 库存 | kind |
|---|---|---|
| 抽象概念/数据/流程/情绪空镜 | 任意 | code-scene（委托美术摄影部，本部只登记） |
| 具体指称物 | 库存有匹配 | user-material |
| 具体指称物 | 无匹配 + code-first | code-scene |
| 具体指称物 | 无匹配 + real-first | imported 或 cloud |
| 用户显式指定 | — | 遵从 IR |

## 模块四层设计（M5）

- **数据规范**：`AssetRef`/`SourcingPolicy`/`ImportTask`/`MaterialIndex` zod schema；
  `ImportTask { source, range?, target, mode: frame|clip }`。
- **数据存储**：
  - 导入/云端资产 → `projects/<id>/assets/s<NN>/`（项目独占，按镜隔离）；
  - 用户素材**原件复制入库** → `materials/`（不引用原路径，项目可搬迁，V-AST-002）；
  - 共享素材库 `library/`（skill 侧，只读；他项目资产导入源）；
  - 抽帧/切片临时文件 → 系统临时目录（clean 回收）。
- **数据流转**：
  ```
  ensureAssets(p, shotId):
    按 IR kind 分派：
    ├─ code-scene   ──▶ 委托 M4.drawScene（本部登记 AssetRef）
    ├─ user-material──▶ material-indexer 匹配 → 归一化（裁剪/压缩/变速/帧率统一）
    │                  ──▶ assets/s<NN>/ ──▶ AssetRef
    ├─ imported     ──▶ import-pipeline：源(外部视频|URL|他项目资产)
    │                  └─ frame：ffmpeg 抽帧；clip：切片 ──▶ 校验(可解码/时长>0)
    └─ cloud        ──▶ cloud-bridge：connect_cloud_service 取新凭证(禁缓存)
                       ──▶ buddy-cloud.py 子进程提交 ──▶ 轮询 Loop(有界间隔)
                       ──▶ DONE 下载落盘 / FAIL 指数退避 ≤3
    ② 登记 AssetRef + meta（同权标记）→ persist
  ```
- **数据接口**：`ensureAssets(p, shotId): AssetRef`；`importAsset(p, shotId, source)`；
  `indexMaterials(p, paths): MaterialIndex`；`generateCloud(p, shotId)`；
  `matchMaterial(index, need)`。
- **生命周期钩子**：`init(ctx)` 校验 ffmpeg/ffprobe（否则 fail-fast）、注册 library/、
  加载 cloud-bridge 配置；`start()` 启动云端轮询器（有界并发 2）；`stop()` 停止接新
  任务、等在途云端任务终态（优雅退出防半成品）；`destroy()` 清理临时文件
  （try/except 容忍已不存在）。

## 第2层子模块

### material-indexer 用户素材索引

- 本质：把“用户丢进来的一堆文件”变成可决策的结构化库存。
- 规范：`MaterialIndex`（路径/类型/时长/尺寸/标签）；标签由 agent/规则生成。
- 流转：add-material → ffprobe 元数据 → 打标 → 原子写索引 → 通知导演部重算决策。
- 接口：`indexMaterials/matchMaterial`。

### import-pipeline 导入管线

- 本质：外部世界与他项目资产的接入闸门。
- 规范：归一化目标参数来自 meta（帧率/分辨率/画幅）。
- 流转：source 解析 → ffmpeg 抽帧/切片 → 校验 → 落盘登记。
- 边界：仅处理用户自有/指定文件；网络 URL 需用户显式确认来源。

### cloud-bridge 云端生成桥

- 本质：把“最节省”主线之外的兼容能力接进来——且不重造。
- 规范：提交参数映射（video/image/video-fx 三类）；JobId 追踪。
- 流转：**每次调用前经 `connect_cloud_service` 取新凭证** → 子进程提交 → 轮询
  → 下载；提交记录入 `cache/cloud.json`（审计）。
- 提醒：云生成产物落 IR meta，成片交付附版权归属。

## 反例（采购卷种子）

| 反模式 | 现象 | 对策 |
|---|---|---|
| 共享目录写资产 | 跨项目互相覆盖 | V-AST-001 |
| 引用用户原路径 | 项目搬迁即丢素材 | V-AST-002 |
| 凭证复用 | 过期凭证批量失败 | V-AST-003 |
| 贴图了事 | 用户照片无 Ken Burns/调色，与代码素材两种质感 | V-AST-004 + V-CAM-006 |
| 半成品入库 | 云端超时未等终态就停 | 生命周期 stop 纪律 |

# 声音部（M6 voice：声音设计师/混音师·对白面）

> 角色：声音设计师/混音师（对白与混音面）| 上游：编剧部（旁白文本）/用户（录音）|
> 下游：剪辑部（A12 混音计划 + 实测时长）| 模块：M6 | 校验域：V-SND-* | 反例卷：声音卷

## 部门职责

两件事：**生产旁白**（TTS 或采用用户真人录音）并**测量真实时长**——这是全片唯一的
时间真源；**制定混音计划**（旁白/BGM/音效三层 + ducking 包络 + 音效落点）。
声音部管着“时间”：镜头多长不靠估算，靠量。

## 理论锚点

| 理论/实践 | 转译 |
|---|---|
| Murch 声音分层 | 旁白（解释）/BGM（情绪结构）/音效（动作锚点）各司其职 → V-SND-001 |
| “声音先行” | 旁白时长驱动剪辑（而非先剪画面后配音）→ V-SND-002 时间真源 |
| Ducking 混音标准 | 旁白区间 BGM 压至 15-20% → V-SND-005 |
| 音效锚点实践 | whoosh@转场 / hit@重音 / riser@高潮前 → V-SND-003 |
| 字幕词边界实践 | 词级时间优先、标点等分兜底 → V-SND-004 |

## 输入输出工件

- **输入**：A2 的旁白文本（每镜一段）+ 用户录音（可选）+ 风格包/recipe 的
  BGM 情绪弧与音效集。
- **输出工件 A12**：`VoiceRef { file, durationMs, voice, rate, source: tts|recording }`
  （登记 IR）+ `MixPlan { tracks[], duckEnv[], sfxCues[] }`（落 IR.timeline.audio）。

## 模块四层设计（M6）

- **数据规范**：`VoiceRef`/`MixPlan` zod schema；`source` 区分合成与录音
  （录音保留原声，不做降噪失真）。
- **数据存储**：
  - 旁白落 `projects/<id>/audio/vo/s<NN>.mp3`（**按项目隔离，禁共享目录**，
    V-SND-006——从结构上排除串音）；
  - 用户录音原样保留于 `materials/`，复制入库；
  - BGM/音效落 `audio/bgm`、`audio/sfx`（来源：用户导入/共享库）。
- **数据流转**：
  ```
  synthesize(p, shotId?):
    旁白文本 → TTS 客户端合成（provider 可换：edge-tts 默认；失败换 provider ≤1）
      └─ 或采用用户录音（--from）
    → 写 audio/vo/ → ffprobe 实测时长 → 登记 VoiceRef → persist
  planMix(timeline, style, recipe):
    旁白轨 + BGM（情绪弧）→ ducking 包络（覆盖全部旁白区间）→ 音效落点
      （每个音效必须对齐某剪切点或重音点，V-SND-003）→ MixPlan
  ```
- **数据接口**：`synthesize(p, shotId?): VoiceRef`；`measureDuration(file): number`；
  `planMix(timeline, style, recipe): MixPlan`。
- **生命周期钩子**：`init(ctx)` 注入 tts-client（provider 接口，默认 edge-tts 协议
  Node 实现，备选本地 Kokoro）；`start/stop` 控制合成并发；`destroy` 显式声明
  无独占资源。

## 本部门校验域（10 的引用）

V-SND-001 三层声音各司其职 / 002 旁白时长为时间真源（与 V-CMP-001 联合）/
003 音效落点对齐 / 004 字幕词边界策略 / 005 ducking 覆盖 / 006 音频按项目隔离。

## 反例（声音卷种子）

| 反模式 | 现象 | 对策 |
|---|---|---|
| 共享音频目录 | 项目间旁白张冠李戴 | V-SND-006（按项目隔离） |
| BGM 盖旁白 | 人声被音乐压住 | V-SND-005 |
| 音效乱落 | 转场音画错位 | V-SND-003 |
| 估算时长 | 音画累计漂移 | V-SND-002 + V-CMP-001 |
| 录音过度处理 | 用户原声被降噪失真 | 保留原声纪律 |

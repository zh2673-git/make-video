# 剪辑部（M7 composer：剪辑师 + 场记 + 调色师）

> 角色：剪辑师（节奏/结构）+ 场记（连续性）+ 调色师（色彩分级）| 上游：美术摄影部
> （场景）/采购部（A11 资产）/声音部（A12）| 下游：工程部（合成项目）|
> 模块：M7 | 校验域：V-CMP-*、V-RHY-*、V-CON-*、V-STYLE-002 | 反例卷：剪辑卷/场记卷/调色卷

## 部门职责

剪辑部是全片的**链接器与质量闸门**，干四件事：

1. **质量闸门**：素材齐全/时长对齐/V-* 不变量——不过不出链接产物（阻断式）；
2. **时间线**：按音画同步不变量把就绪素材铺成轨道，剪切点按 Rule of Six 优先级选取；
3. **连续性**：产出跨镜一致性报告（场记工件 A10）；
4. **合成项目生成**：Timeline → HyperFrames 项目（机器生成全部时间轴属性，
   注入风格/配方参数——调色在本部落地为 effects 组）。

## 理论锚点

| 理论 | 转译 |
|---|---|
| Walter Murch《眨眼之间》Rule of Six | 剪切点决策优先级：情绪 51% > 故事 23% > 节奏 10% > 视线 7% > 2D 5% > 3D 4% → V-RHY-001 候选集与优先级 |
| 心理眨眼理论 | 剪切点落在句读/停顿/重音 → V-RHY-001/002 |
| “剪辑是最后一次改写” | 结构问题在剪辑层最后可修 → 时间线快照可回放可精修 |
| 紧张-松弛波 | 呼吸镜每 4-6 镜 → V-RHY-005 |
| 认知负荷 | 每 2-3s 一次视觉变化 → V-RHY-006 |
| 连续性剪辑（轴线/色温/道具） | 场记 A10 → V-CON-001~005 |
| 色彩情绪/LUT 传统 | 风格包 effects grade 组 → 调色参数注入 |

## 输入输出工件

- **输入**：就绪镜头（voiced + sourced）+ 场景文件 + A11 资产 + A12 混音计划
  + 风格包/配方参数（M10 解析）。
- **输出工件**：
  - **A8 时间线 + 剪切点审计**：`Timeline { shots[{startMs,durationMs,transition,coverage,camera,motivation,audioShiftMs}], bgm?, subtitles[], sfx[] }`
    + 每个剪切点的候选来源、切点动机、match-cut 锚点、J/L cut 偏移与优先级依据（`logs/cut-audit.json`）；
  - **A10 连续性报告**：跨镜轴线/色温/道具/token 一致性清单（进 logs + IR）；
  - **合成项目**：`remotion/`（index.html + compositions/ + data 属性 + window.__timelines + window.__captions）。

## 核心不变量（本部之根）

```
shot[i].startMs = Σ_{j<i} durationMs(j)，  durationMs = voiceRef.durationMs（旁白时长为唯一真源）
```

推论：**时间轴属性只允许本部机器生成**（场景代码禁时序 V-SCENE-002 ↔ V-CMP-002
互为表里）；镜头时长来自“量出来多久”，不是“估算了多久”。

**J-cut / L-cut 的边界**：允许把旁白音频 clip 的 `data-start` 相对画面切点前后微移
（`audioShiftMs`，±200ms，软转场默认 -90ms 让声音先入），但 `Timeline.startMs` 与
`durationMs` 一律不动——声音可以踩点前后，画面时长仍是旁白实测（V-CMP-001 不破）。

## 模块四层设计（M7）

- **数据规范**：`Timeline`/`SubtitleCue`/`ContinuityReport` zod schema；
  `SubtitleCue { shotId, startMs, endMs, text, keywords[] }`（keywords 驱动词级高亮）。
- **数据存储**：合成项目 `projects/<id>/remotion/`；时间线快照 `project.json.timeline`；
  连续性报告与剪切点审计 `logs/`。
- **数据流转**：
  ```
  compose(p):
    ① validateReadiness（质量闸门，任一 Issue 即阻断并输出清单）：
       素材齐全（V-AST-005 复检）+ 时长对齐（V-CMP-001）+ V-* 全家桶 + V-STYLE-*
    ② continuityReport（场记：V-CON-*，产出 A10）
    ③ 参数注入：style tokens + motion + effects（调色）→ 场景根 CSS 变量
    ④ timeline-calc：不变量计算 + 切点裁决（adjudicateCuts）——
       锚点相同判 match-cut 硬切；转场未指定（空/auto）由切点动机决定
       （情绪→溶解，动作·节拍→冲击切，其余硬切）；显式声明仍按风格包 transitions 词表
    ④b camera-rig：按景别/运动式/主语焦点算外层机位三段式 + 镜内覆盖切点（见 05）
    ④c audio-shift：J/L cut 只移音频 clip 落点（±200ms），不动时间线时长
    ⑤ subtitle-gen：cues（词边界优先，标点等分兜底 V-SND-004）
    ⑥ audio-mix：与声音部共管 A12 落地（旁白+BGM ducking+音效落点）
    ⑦ hyperframes-emitter：生成合成项目（clip 的 data-start/duration/track-index
       视频轨/字幕轨/BGM 轨/音效轨分 index；window.__timelines；window.__captions）
    ⑧ 时间线快照 persist → 交工程部
  ```
- **数据接口**：`validateReadiness(p): Issue[]`；
  `continuityReport(p): ContinuityReport`；
  `compose(p): Timeline`（幂等：覆盖生成，保留上次成功快照）。
- **生命周期钩子**：`init(ctx)` 注册合成项目根、加载 M10 参数解析器；
  `start()` 打开装配会话（加载 ready/voiced 集）；`stop()` 提交时间线快照（原子）；
  `destroy()` 清理过期装配产物（保留最近一次成功装配）。

## 第2层子模块

### timeline-calc 时间线计算（剪辑师的手）

- 本质：音画同步不变量的执行体——“量出来的时长”到“铺出来的轨道”。
- 规范：剪切点候选集 = {句读停顿， 重音词， 景别变化点， 色温变化点， 切点动机}，
  按 Rule of Six 优先级选取（V-RHY-001）；句中切必须有动机（V-RHY-002 修订）。
- 接口：`calcTimeline(shots, style, recipe)`。

### cut-adjudicate 切点裁决（剪辑师的判断）

- 本质：把「导演写了什么转场」翻译成「观众眼里接不接得上」——转场不是装饰，是切点
  动机的视觉答案。
- 规范：动机词表 `match-cut/action/eye-line/emotion/beat/zoom-jump`；转场词只说明
  「怎么接」不说明「为什么切」，**不计入动机**（缺动机单独审计）；
  `emotion → dissolve`、`action/beat → smash-cut`、其余 `hard-cut`；显式声明与动机冲突时
  **保留声明、只写审计 note**（不擅自改片）。
- **动机三来源（P2）**：① 导演文案（`shot.motivation`）；② match-cut 锚点（相邻镜
  `exitAnchor==enterAnchor`）；③ 结构关系反推（导演没写清时，剪辑部按客观关系判定：
  景别跨两档→`zoom-jump`，同场主体方位反转→`eye-line`，笑点落镜→`beat`）。
  优先级 ②>①>③，来源写入 `logs/cut-audit.json` 的 `motiveSource`（text/anchor/relation/none）。
- 接口：`adjudicateCuts(p, timeline, pack): (CutDecision|null)[]`；
  `applyAudioShifts(p, timeline, decisions)`；`deriveRelationMotivation(prev, cur)`。

### subtitle-gen 字幕生成

- 本质：旁白 → 可读的时间轴字幕（DOM 组件，非烧录）。
- 规范：词级高亮 keywords 来自分镜重音标注；词边界优先、标点等分兜底。
- 接口：`genCues(shots, timeline)`。

### hyperframes-emitter 合成项目生成器（对渲染后端的唯一出口）

- 本质：Timeline → HyperFrames 项目文件的代码生成。
- 规范：HyperFrames 契约（data-composition-id/width/height；clip 属性；
  window.__timelines；window.__captions）。
- 边界：只许生成合法结构；换渲染后端（Remotion）时仅替换本子模块（与工程部适配器成对）。

### audio-mix（与声音部共管）

- 本部负责落地声音部的 A12；ducking 包络与音效落点校验见 07。

## 本部门校验域（10 的引用）

V-CMP-001~005（音画同步/时序唯一来源/阻断闸门/ducking 覆盖/音效落点）/
V-RHY-001~008、010、011（剪辑全系：候选集/无动机切/密度/重音/呼吸/变化/镜头内运动/切点动机）/
V-CON-001~005（场记）/ V-STYLE-002（组合一致性）。

## 反例（剪辑卷/场记卷/调色卷种子）

| 反模式 | 角色 | 现象 | 对策 |
|---|---|---|---|
| 随机剪切 | 剪辑 | 剪切点无候选依据 | V-RHY-001 |
| 均分切镜 | 剪辑 | 按字数把长句硬切成几镜，观众看不到理由 | V-RHY-002（修订） |
| 幻灯片长镜 | 剪辑 | 一镜到底且**画面里什么都不动**（不是"没有外层机位"：静止构图 + 镜内表演成立） | V-RHY-010 / V-RHY-006 |
| 单一动机 | 剪辑 | 全片只有一个转场理由（永远硬切或永远溶解） | V-RHY-011 |
| 密度呆板 | 剪辑 | 全程同镜长无起伏 | V-RHY-003 |
| 无呼吸镜 | 剪辑 | 高密度轰炸到底 | V-RHY-005 |
| 跨镜跳轴 | 场记 | 主体方位横跳不自知 | V-CON-001 |
| 色温跳变 | 场记 | 相邻镜气质断裂 | V-CON-002 |
| 滤镜混搭 | 调色 | 风格包之间 effects 乱叠 | V-STYLE-002 |

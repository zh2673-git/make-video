# make-video 视觉与剪辑规范（公共法律）

> 本篇是 **V-\* 不变量的唯一权威登记处**。各部门（03-09）只引用、不重复定义；
> 风格包与配方（11）只能在这些不变量的参数空间内取值；违反即阻断，无例外。
>
> 理论谱系：场面调度 / 动画十二原则 / 格式塔 / 蒙太奇与 Walter Murch Rule of Six /
> 声画对位 / 认知负荷理论 / 动态排版传统（Saul Bass 一脉）/ Ed Hooks 动画表演 /
> 编剧结构理论（Syd Field、Save the Cat）/ **信息设计（Tufte 数据墨水）** /
> **多媒体学习原则（Mayer）** / 古典好莱坞连续性剪辑（默认叙事语法）。
> 校验器编号规则：V-<域>-<序号>；实现于 `src/core/validators/`；单测全覆盖。

## 总则

1. 规范管"不许做什么"，风格包（11）管"偏好什么"，配方（11）管"这类视频通常怎么配"。
2. 每条不变量三要素：**规则 / 理论出处 / 校验方式与失败处理**。
3. 校验失败分级：`error`（阻断装配/渲染）与 `warn`（记录不阻断，进反模式统计）。
4. 域与主管部门对应（角色视角的落地）：

| 校验域 | 前缀 | 主管部门 | 理论谱系 |
|---|---|---|---|
| 编剧功能 | V-SCP | 编剧部（03） | 三幕/Save the Cat/功能三问/Mayer（教育类）/认知负荷 |
| 场景结构 | V-SCENE | 美术摄影部（05） | 模板化工程纪律 |

## 五、动效规范 V-MOT-*（美术摄影部）

### 5.1 十二原则转译

| ID | 规则 | 原则出处 | 校验方式 |
|---|---|---|---|
| V-MOT-001 | 入场默认 ease-out-expo；退场对偶；缓动只许来自 motion 组 token | 慢入慢出；Penner 缓动 | error：场景扫描非白名单 easing |
| V-MOT-002 | anticipation：重要主体入场前 60-100ms 预备反向位移（3%） | 预备动作 | warn：模板遵守检查 |
| V-MOT-003 | follow-through：主体落定必有过冲回弹（8-12%） | 跟随与重叠 | warn |
| V-MOT-004 | staging：非主语元素透明度 ≤70% 服务主语 | 布局/表演 | error：层级透明度检查 |
| V-MOT-005 | arcs：位移必须沿曲线（禁止直线匀速） | 弧形运动 | error：原语调用检查 |
| V-MOT-006 | secondary action：装饰层独立微动（不与主语同步） | 附属动作 | warn |
| V-MOT-007 | exaggeration：急推仅允许 ±12% 且全片 ≤2 次 | 夸张 | error：相机参数检查 |
| V-MOT-008 | timing：时长必须在 token 区间（微 200-400 / 入场 400-800 / 转场 300-600 / 强调循环 1200-2000ms） | 时间控制 | error：motion profile 检查 |

### 5.2 并发约束（格式塔共同命运）

| ID | 规则 | 出处 | 校验 |
|---|---|---|---|
| V-MOT-010 | 同屏同时运动元素 ≤3 | 共同命运；认知负荷 | error：时间线并行运动分析 |
| V-MOT-011 | 同屏运动方向 ≤2；同组元素必须共用 easing/方向/delay 阶梯 | 共同命运（同向=同组） | error |

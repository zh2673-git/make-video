# makevideo 使用指南

## SCENE u1 | title | makevideo：讲稿进，成片出

subtitle: 讲稿驱动的微视频生成工具
subtitle: 从 Markdown 讲稿到 1080P 成片

=== narration
写好一份讲稿，选一个风格主题，敲一条命令，就能得到一支 1080P 的成片。这里就是 makevideo，一个讲稿驱动的微视频生成工具。这一集，我们用它自己来介绍它自己：从讲稿到成片，完整走一遍。

## SCENE u2 | bullets | makevideo 解决什么问题

- 讲稿驱动：内容集中在一份 Markdown
- 主题驱动：风格沉淀为可复用的主题包
- 增量渲染：改动只重画对应的分镜

=== narration
传统做讲解视频，要在剪辑软件里逐页排版、逐句配音。makevideo 把这个过程反过来：你只负责写讲稿，排版交给主题，配音和渲染全部自动。内容、风格、流程三者分离，改哪一个，都不会牵动其余两个。

## SCENE u3 | flow | 三步，从讲稿到成片

- 第一步 写讲稿：Markdown 里分镜
- 第二步 选主题：一行配置定风格
- 第三步 跑命令：一键出片

=== narration
使用流程只有三步。第一步，在讲稿里用分镜语法组织内容，每个分镜写清版式、画面和旁白。第二步，在工程配置里选定一个主题，风格就定下来了。第三步，执行一条命令，工具自动完成配音、对齐和渲染。

## SCENE u4 | code | 命令行只有四条

lang: bash
- # 校验：讲稿与主题是否合规
- python -m makevideo validate projects/demo
- # 出片：配音、对齐、渲染一次完成
- python -m makevideo build projects/demo
- # 增量：只重渲染第 3 个分镜
- python -m makevideo build projects/demo --only 03
- # 试帧：渲染样例页预览主题效果
- python -m makevideo preview --theme techdark

=== narration
日常使用就是这四条命令。写完讲稿先跑校验，语法错误当场报出来。校验通过后跑 build，工具自动完成配音、帧对齐和渲染，直接输出成片。改了某个分镜，加一个 only 参数，几十秒就能换掉那一段。选主题拿不准，先用 preview 渲几帧看看效果。

## SCENE u5 | table | 十二种分镜版式，覆盖讲解场景

| 类型 | 用途 |
| title | 片头：标题与副标题 |
| bullets | 要点：逐条弹入的列表 |
| flow | 流程：步骤卡片横排 |
| table | 表格：数据高亮与标注 |
| code | 代码：终端风格逐行展示 |
| compare | 对比：左右分栏对照 |
| timeline | 时间轴：节点顺序展开 |
| quote | 金句：大字号引言页 |
| image | 配图：图片与注解 |
| ending | 片尾：致谢与署名 |

note: 另有 panorama 全景表格与 chart 数据图表

=== narration
画面不靠手画，靠版式。工具内置十二种分镜版式：片头、要点、流程、表格、代码、对比、时间轴、金句、配图、片尾，还有全景表格和数据图表。每个分镜在讲稿里声明版式，渲染引擎套用对应组件，主题负责皮肤，内容零改动就能换风格。

## SCENE u6 | compare | 整片渲染与增量渲染

leftTitle: 整片渲染
rightTitle: 增量渲染
- 首次出片的标准路径|迭代打磨的日常路径
- 从第一帧画到最后一帧|只重画改动的分镜
- 其余分镜全部重跑|未改动的片段直接复用

=== narration
渲染有两种模式。整片渲染把所有分镜从头画到尾，适合首次出片。日常打磨用增量：在命令里指明改动的分镜，只有它被重新渲染，其余片段从缓存直接复用，拼接依然是无损的。改动再小，也不必整片重跑。

## SCENE u7 | timeline | 一条命令背后，五个阶段

- 解析|讲稿切分为分镜，双重校验
- 配音|逐镜合成旁白，词级时间戳
- 对齐|音频秒数换算帧数，字幕对帧
- 渲染|React 组件逐帧绘制画面
- 拼接|无损合并分段，封装成片

=== narration
一条 build 命令背后，是一条顺序管道：解析讲稿并校验，逐分镜合成配音，用词级时间戳把音频时长换算成帧数，再驱动组件逐帧绘制画面，最后无损拼接封装。每个阶段失败即停，问题出在哪一步，就报在哪一步。

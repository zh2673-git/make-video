## SCENE c2|bullets|做一条介绍视频

icons: edit,grid,mic
- 写文案
- 排层面
- 配音对轴

=== narration
做一条介绍视频，通常要过三道工序。写文案、排版面、配音对轴，缺一不可。最耗时的不是内容，而是这些重复劳动。MakeVideo 把它们压成一条命令：配音、排版、渲染全部自动完成。

## SCENE c3|flow|它的用法只有三步

- 用 Markdown 写讲稿，声明每页版式
- 挑一套设计主题
- 运行 build 命令，成片自动落盘

=== narration
它的用法只有三步： 1. 用 Markdown 写讲稿，声明每页版式 2. 挑一套设计主题 3. 运行 build 命令，成片自动落盘 改完讲稿再跑一次，只有改动过的分镜会重新渲染。
